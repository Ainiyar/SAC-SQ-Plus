# Figure and numerical-data provenance

The five PNGs under `reproduction/R392-R393/figures/` are the exact R395 figure assets carried into the R400 manuscript. Their numerical backing tables are retained in `reproduction/R392-R393/figure_data/`, including the R380 stagewise CPU table, R382 pairwise ablation summary, R390 n=256 timing records, R393 synthetic comparison, and R399 workload summaries.

The original vector-drawing source for the five final R395 PNGs was not present in the R396/R400 submission archive. The repository therefore preserves the exact manuscript-used images and the underlying numeric data rather than claiming that a newly written plotting script regenerates the identical artwork. The algorithm, data, and result-generation source code required for the paper's scientific computations is included separately.
