# R372 Occupancy n=256 pair

This pair contributes two workload arms to the 11-box R399 comparison: the persistent-pricing baseline and the certificate-bank-pricing arm. Both use the same frozen X/y window, same method settings, and same action budget. The archived JSON/NPZ outputs, action trace, proof-progress trace, and pair summary are retained in this folder. The portable source and runner are under `acquisition/r372/` and `acquisition/scripts/run_r372_pair.py`.
